Developer

Free

For individual developers, prototypes and AI experiments.

“Build an AI application on a real dedicated PostgreSQL database with MaluDB memory architecture without assembling infrastructure.”

ClaimStatusWhat's true today
Real dedicated PostgreSQL databaseReady nowEvery project gets its own database. It runs on a shared server, so “your own database” is accurate and “dedicated server” is not.
Without assembling infrastructureReady nowData API, Auth, file Storage, a SQL console and backups are all set up automatically when a project is created.
MaluDB memory architectureSmall changeToday this tier gets vector search and the schema graph. The full memory pipeline isn't available on any tier yet, so the wording needs to change.
The “Developer” nameSmall changeA display-name change on the current Free plan.
Say

“Your own PostgreSQL database with built-in vector search, free.”

Don't say

“Dedicated server” or “full MaluDB memory architecture.”

Builder

$49/mo

For founders, startups and a single production app.

“One production-ready backend for application data + persistent AI memory + hybrid search.”

ClaimStatusWhat's true today
Production-ready backendReady nowToday's Starter plan: direct database connections, point-in-time recovery over 7 days, realtime, always-warm APIs, predictable hard limits.
Application dataReady nowSupabase-compatible data API, auth, storage and realtime.
Persistent AI memorySmall changeTrue if it means stored vector embeddings, which survive restores and moves. If a buyer hears the full memory pipeline, that is a major build (see Professional).
Hybrid searchSmall changeCustomers can already combine vector and keyword search in their own SQL. A built-in hybrid search function is one small feature that engineering hasn't built yet.
Single production app at $49Small changePlans are already per project, so this fits billing. Needs a price set up and a lower project cap than Starter's current 20.
Say

“Production backend with vector search and point-in-time recovery.” Add “hybrid search” once it ships.

Don't say

“Hybrid search” as a built-in feature yet, or “AI memory” in a way that implies facts, episodes or agent memory.

Professional

$149/mo

For production AI products and development teams.

“Complete governed memory infrastructure for multiple agents, applications and workflows.”

ClaimStatusWhat's true today
Production team capacityReady nowThe Professional plan (formerly Production), retuned for $149: 50 GB database, 100 GB files, 250 GB egress a month, 14 days of point-in-time recovery within 30 days of backups, 25 projects.
TeamReady nowOrganizations, roles, invitations and required MFA already exist.
Complete memory infrastructureMajor buildMaluDB's memory pipeline and knowledge graph aren't exposed yet. They're waiting on a fix in MaluDB itself so memory data survives backups, restores and moves.
Governed memoryMajor buildMaluDB's governance roles are too powerful to hand to a customer on shared infrastructure. The platform has to build its own safe governance controls on top.
Multiple agentsMajor buildEngineering hasn't yet decided how separate agents or accounts share one project's memory. That design decision comes before any build.
Multiple applications under one planMajor buildToday a plan covers one project. One subscription covering several apps with shared limits changes how plans and billing work.
Say

“Production-scale backend for teams, with 14-day point-in-time recovery and vector search.”

Don't say

“Governed memory,” “multiple agents” or “multiple applications on one plan” until they ship. This is the tier most at risk of overpromising.

Dedicated

$599/mo

For growing companies and serious production deployments.

“Dedicated MaluDB environment with isolation, performance, recovery and advanced administrative control.”

ClaimStatusWhat's true today
IsolationReady nowTenant isolation on shared servers is tested on every change. A dedicated server adds physical separation on top.
RecoveryReady nowContinuous backups, point-in-time restore, and moving a customer between servers are all built.
PerformanceSmall changeHigher limits are plan configuration once the customer has their own server.
Dedicated environmentMajor buildServer pools exist, but they're assigned by plan, not by customer. Giving one customer their own server needs a bounded platform change. Until then, ops can set it up by hand for each sale.
Advanced administrative controlMajor buildNot defined yet. Customers can never get full superuser rights, even on their own server. Product and engineering need to agree what this means (maintenance windows, tuning, extension choice) before it can be built.
$599 price pointNeeds a decisionNobody has costed a whole server plus its services and backups against $599 yet.
Say

“Your own server, isolated from other customers, with point-in-time recovery.” Treat early deals as hand-provisioned.

Don't say

“Full admin” or “superuser access.” Don't quote instant self-serve setup.

Enterprise

From $1,499/mo

For enterprise, regulated and institutional AI.

“Governed organizational memory infrastructure with dedicated deployment, security, auditability, sovereignty and support.”

ClaimStatusWhat's true today
SecurityReady nowEncrypted secrets, tested tenant isolation, audited and time-limited staff access, and a security review required on every code change.
Dedicated deploymentMajor buildSame as Dedicated.
Governed organizational memoryMajor buildEverything under Professional, extended across a whole organization.
AuditabilityMajor buildThe platform keeps its own audit trail, but customers can't see or export audit logs of their data yet.
SovereigntyMajor buildNo way yet to pin a customer's data and backups to a chosen region or country.
Single sign-on (SSO)Major buildNot in the pitch, but enterprise buyers will ask. Not built: sign-in today is email and password plus MFA.
Custom contracts and invoicingMajor buildToday's payment setup handles card subscriptions at fixed prices. It can't do negotiated pricing or custom invoices, which “From $1,499” implies.
SupportNeeds a decisionNo uptime SLA, support hours or on-call rota exist yet. That's a business commitment, not software.
Say

“Talk to us.” Qualify requirements (region, SSO, audit, SLA) and bring engineering in before quoting.

Don't say

“Data sovereignty,” “audit logs,” “SSO” or an SLA figure as available today.

What engineering would need to do

  • Now, small changes: rename and reprice the current plans as Developer and Builder, and tighten Builder's project cap.
  • Next small build: built-in hybrid search, which makes the Builder pitch fully true.
  • Bounded platform change: per-customer servers for Dedicated, plus a cost model for the $599 price and a definition of “administrative control.”
  • Major builds behind Professional: the MaluDB memory pipeline, governance controls, multi-agent memory, and plans that cover several applications.
  • Major builds behind Enterprise: region pinning, customer audit logs, SSO, contract billing, and a support and SLA commitment.
Grades reflect the platform as of 14 September 2026 and will change as work ships. Ask engineering before promising anything graded “Major build” or “Needs a decision.”
