Managed PostgreSQL/MaluDB for Supabase-shaped apps

Ship on a dedicated tenant database without operating the cluster.

MaluDB provisions each project as its own PostgreSQL/MaluDB database, routes API traffic by project identity, and keeps public compatibility close to Supabase where the platform has verified it.

What still belongs to operators.

          

            Node drain, tenant movement, backups, restore, and pool changes are
            intentionally CLI/operator flows in this repo. The customer-facing UI
            should show state and safe requests; it should not invent automatic
            infrastructure actions the backend does not implement.
